# 🏨 Hotel Alvares – Projeto Web com HTML e CSS

Este projeto é uma página web desenvolvida com foco em praticar e consolidar conhecimentos de **HTML5**, **CSS3** e **JavaScript**, simulando o site de um hotel à beira-mar no Algarve, Portugal.

O objetivo é aplicar conceitos de estrutura semântica, estilização avançada, layout responsivo e interatividade básica em um projeto visual e funcional.

---

## 🌐 Demonstração

🔗 Acesse o projeto online:  
👉 [Hotel Alvares](https://giovannacostaxavier.github.io/Projeto-hotel/)

## ✨ Sobre o Projeto

O **Hotel Alvares** é um site institucional de um hotel fictício, que apresenta:

- Página inicial com imagem de capa imersiva e chamada para ação
- Formulário de reserva interativo com seleção de datas e número de hóspedes
- Seção de quartos disponíveis com descrições e visual atraente
- Navegação clara e intuitiva via menu de navegação fixo
- Layout responsivo pensado para diferentes tamanhos de tela
- Design elegante com foco em experiência do usuário (UX)

## 🧩 Funcionalidades

### 🔝 Navegação

- Menu de navegação com links para as seções:
  - **Sobre nós**
  - **Contacte-nos**
  - **Reserve já**
- Navegação suave entre seções da página (scroll interno)

### 🖼 Seção de Capa

- Imagem de destaque em tela cheia com texto sobreposto
- Botão de chamada para ação **"Reserve já"** em destaque

### 📅 Formulário de Reserva

- Campo de **Check-in** para seleção de data de entrada
- Campo de **Check-out** para seleção de data de saída
- Seletor de **número de hóspedes** (1, 2 ou 3 hóspedes)
- Botão **"Verificar disponibilidade"** para submissão do formulário

### 🛏 Seção de Quartos

- Exibição dos tipos de quartos disponíveis
- Apresentação visual com imagens, descrições e características

  - `header`

  - `section`
  - `footer`

  - apelo estético
